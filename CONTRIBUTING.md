# Contributing and reporting discrepancies

Please open an issue with the precise equation, cited source, reproduction commands, or mathematical counterexample. Separate an actual mathematical error from a hypothetical story-model assumption.

Contributions should not claim real observed probabilities in *Hardcore Leveling Warrior* unless the relevant primary panel is independently verifiable. Do not upload copyrighted comic panels or third-party materials without permission.

Before proposing any change, run `bash tools/run_regression.sh` and `bash tools/build_publications.sh` with the dependencies described in `README.md`. The reference PDF outputs may differ at the byte level across LaTeX/renderer versions; validate page counts, figures, and mathematical content instead.

Scientific manuscript authorship and reuse licensing remain to be confirmed by the repository maintainer. No open-source license is granted by this file.
